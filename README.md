# 🏋️‍♂️ GymClub - Responsive React Fitness Website

A fully responsive fitness website built with **React.js** and styled using **Tailwind CSS**, featuring smooth animations powered by **Framer Motion**.

This project showcases a modern landing page for a fitness club, designed for real-world use.

---

## 🚀 Features

- ⚛️ Built with **React 18**
- 💨 Styled with **Tailwind CSS**
- 🎬 Animations with **Framer Motion**
- 📱 Fully **responsive design**
- 🧭 Smooth navigation and scroll
- 📦 Modular & reusable components
